# Annareddy Tharuni — Data Analyst Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.

## Before publishing
- Verify your email and LinkedIn URL.
- Replace each project card's GitHub profile link with the specific repository URL when available.
- Add a resume PDF link if you want a downloadable resume button.
- Keep project descriptions and tools accurate to your actual contributions.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `tharuni-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the Pages URL to appear in the Pages section. It will usually look like `https://YOUR-USERNAME.github.io/tharuni-portfolio/`.

## Notes
- This site uses Google Fonts, which require an internet connection to load.
- The project art is CSS illustration, so no image assets are needed.
